01

Web corporativa

Diseño y maquetación · HTML + CSS

Estructura semántica, navegación clara y una hoja de estilos mantenible. La primera vez que entendí que una web es un documento antes que un dibujo.

  • HTML5
  • CSS
  • Semántica
  • Responsive
Caso de estudio
Problema
Presentar una empresa con una web clara y fácil de mantener, sin frameworks ni plantillas.
Solución
HTML5 semántico (header, nav, main, footer), CSS con variables y maquetación responsive con Grid y Flexbox.
Resultado
Una web navegable con teclado, que se adapta al móvil y donde cambiar un color o una fuente es tocar una sola línea.

02

Aplicaciones de consola (CLI)

Desarrollo · Python

Menús, validación de datos, ficheros y menú persistente. Sin interfaz gráfica donde esconderse: lógica pura y mensajes de error que el usuario entiende.

  • Python
  • Funciones
  • Ficheros
  • Excepciones
Caso de estudio
Problema
Un programa de consola que no se rompa cuando el usuario escribe algo inesperado (letras donde va un número, opciones inexistentes).
Solución
Menú en bucle, funciones pequeñas con una sola responsabilidad, validación de cada entrada, ficheros para guardar datos y try/except con mensajes claros.
Resultado
La aplicación no se cierra por errores no controlados y conserva los datos entre ejecuciones.

03

Laboratorio de bajo nivel

Autoaprendizaje · Sistemas

Prácticas de memoria, procesos y redes: ver el mapa de un programa, abrir un binario, mirar cabeceras y medir lo que cuesta cada operación.

  • Sistemas
  • Redes
  • Linux
  • Depuración
Caso de estudio
Problema
Entender qué hace realmente un programa por debajo: dónde vive cada variable y qué viaja por la red.
Solución
Prácticas en Linux: inspeccionar el mapa de memoria de un proceso, examinar binarios, leer cabeceras de red y medir tiempos de operaciones.
Resultado
Sé explicar la diferencia entre pila y montón, y lo aplico en esta web: el conversor de «Bajo el capó» muestra un número en hex, binario y bytes.
